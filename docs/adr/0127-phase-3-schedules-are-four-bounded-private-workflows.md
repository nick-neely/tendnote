# Phase 3 Schedules Are Four Bounded Private Workflows

Phase 3 should include four baseline private scheduled workflows: Morning Agenda, Post-Meeting Aftercare, Weekly Relationship Review, and Birthday/Gift Planning. These workflows should use app-owned dispatcher rows and shared owner-scoped product functions, while continuous background scanning, arbitrary high-frequency sweeps, autonomous draft creation, unconfigured Discord push delivery, and shared-household-aware scheduling stay out of scope.
