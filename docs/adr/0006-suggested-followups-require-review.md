# Suggested Follow-Ups Require Review

Phase 1 supports both user-created follow-ups and agent-suggested follow-ups, but they are different states. A user-created follow-up is an active reminder; an agent-suggested follow-up is a proposed action that can be accepted, dismissed, or shown as low-weight context before it becomes a normal due reminder.

This keeps Tendnote useful enough to suggest timely relationship actions without letting the daily brief turn into an automatically generated task list.
