# Google Contacts Import Does Not Add Transactional Undo

Phase 2E should show clear post-confirmation feedback and let users inspect what changed, then rely on normal profile editing and archiving flows for corrections. It should not add a dedicated transactional undo system for imported contacts in the first slice, because rolling back newly created people, added contact methods, birthday updates, conflict resolutions, and future linked records is complex enough to deserve a later phase if real usage proves it necessary.
