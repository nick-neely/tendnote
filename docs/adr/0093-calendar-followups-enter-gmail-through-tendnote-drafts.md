# Calendar Follow-Ups Enter Gmail Through Tendnote Drafts

Phase 2D may let Calendar-derived follow-up suggestions lead to Gmail draft creation, but only by passing through the normal Tendnote follow-up and message-draft lifecycle. A reviewed Calendar suggestion can ground a Tendnote draft, the user can revise and approve that draft, and then Tendnote can create or update the Gmail draft through the shared external-action approval gate. Calendar context and unreviewed suggested follow-ups should not skip directly to Gmail draft creation.
