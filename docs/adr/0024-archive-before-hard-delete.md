# Archive Before Hard Delete

Phase 1 product flows should use archive and dismiss lifecycle states for source records, memories, follow-ups, drafts, and brief items rather than hard-deleting normal user actions. This preserves auditability, prevents dismissed suggestions from being reintroduced, and keeps relationship context explainable.

Hard delete should be a separate privacy and data-deletion workflow for cases such as deleting a person, deleting a user account, removing raw retained content, deleting embeddings, or satisfying future export/delete requirements.
