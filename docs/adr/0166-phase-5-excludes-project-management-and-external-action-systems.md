# Phase 5 Excludes Project Management And External Action Systems

Phase 5 should focus on Tendnote-owned Actions and Routines as the first broader Personal OS action layer, not full project management or external task systems. Projects, subtasks, dependencies, kanban boards, assignment workflows, complex recurrence rules, external task or calendar writes, standalone notifications, file management, asset records, full Today, productivity analytics, autonomous cleanup, broad background scanning, nested taxonomies, and provider-side task sync remain out of scope.
