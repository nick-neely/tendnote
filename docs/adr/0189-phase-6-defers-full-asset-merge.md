# Phase 6 Defers Full Asset Merge

Phase 6 should include lightweight duplicate detection during asset review so Tendnote can suggest linking a Suggested Asset or captured asset context to an existing Asset before creating a near-duplicate. Full Asset merge should be deferred because it would need to reconcile Asset Memories, Asset Evidence, related General Actions, Related Asset Links, Asset Person Links, Asset Snapshots, search embeddings, and audit history before real usage proves the right repair workflow.
