# Global Assistant With Context

Phase 1A should provide a global assistant surface that can capture notes, create source records, route to people, and surface review components from anywhere in Tendnote. When the assistant is launched from a person profile, source record, suggested memory, follow-up, or brief item, it should receive that context explicitly so it can reduce ambiguity and render relevant structured components.

This keeps Tendnote fluid and useful for quick capture while preserving person-centered review when the user is already working in a specific relationship context.
