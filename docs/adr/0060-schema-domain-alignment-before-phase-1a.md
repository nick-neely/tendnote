# Schema Domain Alignment Before Phase 1A

Before Phase 1A product work begins, Tendnote should run a schema and domain alignment slice that updates Phase 0 assumptions to match the settled memory, source-record, privacy, and assistant-surface decisions. This slice should update shared domain schemas, Drizzle schema, migrations, query helpers, seed data, and policy tests before building new capture, review, follow-up, brief, or drafting UI.

This is effectively a pre-Phase-1A prerequisite: the product surfaces should be built on the correct source-record and memory lifecycle model rather than carrying forward incompatible Phase 0 scaffolding.
