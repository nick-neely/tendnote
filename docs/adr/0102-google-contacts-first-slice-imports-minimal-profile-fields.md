# Google Contacts First Slice Imports Minimal Profile Fields

Phase 2E should import only the minimal Google Contacts fields that make Tendnote more useful without becoming a contact manager: display name, email addresses, phone numbers, and birthdays. Organizations, job titles, photos, postal addresses, biographies, relationship labels, notes, groups, and arbitrary People API metadata should stay out of the first slice until Tendnote has a clearer product use for them and privacy/review rules to match.
