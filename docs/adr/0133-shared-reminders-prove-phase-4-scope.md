# Shared Reminders Prove Phase 4 Scope

Phase 4 should use minimal shared reminder behavior as the proof artifact for Household Workspace visibility because reminders exercise membership, record scope, listing, status changes, Eve responses, scheduled/proactive visibility, and audit with less privacy risk than shared memories or shared drafts. Shared memories and shared drafts are not forbidden; they are deferred until richer household collaboration, likely Phase 8, after the scope substrate is proven.
