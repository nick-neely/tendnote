# Eve Can Read Connected Calendar Live

Phase 2C should let Eve use a narrow live Google Calendar read tool after the owner connects Calendar, rather than limiting Eve to persisted Tendnote records or a separate preview surface. The tool should return minimized event summaries for bounded windows and should not write memories, source records, follow-ups, drafts, or external actions by itself. Durable product writes remain explicit Tendnote mutations with existing review, audit, and source-grounding rules.
