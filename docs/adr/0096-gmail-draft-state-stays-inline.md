# Gmail Draft State Stays Inline

Phase 2D should show Gmail draft creation and update state inline wherever the related Tendnote message draft already appears, such as the draft review card, person ledger, or assistant-rendered draft card. It should not add a separate Gmail draft history, inbox, outbox, or provider artifact page in the first slice. This keeps the Tendnote message draft as the source of truth while still making external draft state visible, retryable, and explainable.
