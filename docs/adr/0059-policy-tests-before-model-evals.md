# Policy Tests Before Model Evals

Phase 1A should add deterministic policy tests before LLM extraction and drafting exist. Tests should cover rules such as restricted content being excluded from proactive retrieval, dismissed memories being ignored, suggested memories not being stated as facts, pending source records not feeding normal contexts, duplicate names requiring disambiguation, and memory writes requiring source records.

Model evals for no-fake-memory, tone, source-grounded recall, extraction quality, and draft quality should be added when model behavior enters those flows.
