# Phase 6 Defers Asset Provider Imports

Phase 6 should not import asset context directly from external providers such as Gmail receipts, Google Drive, Amazon or order history, banking or card transactions, Home Assistant, merchant accounts, or warranty and service portals. These integrations are highly useful follow-ups, but the first Asset Memory phase should prove manual capture, upload, links, source records, Eve, review, provenance, and scope filtering before adding new consent scopes, provider minimization rules, background jobs, dedupe pressure, and extraction-quality risks.
