# Closeness Level Is Internal Ranking

Phase 1A should keep `closeness_level` as internal ranking metadata for future brief relevance, stale-contact suggestions, birthday prioritization, and weekly review, but it should not be exposed as a required user control during capture.

The field can default to a neutral value and later be adjusted through softer user-facing affordances or inferred correction signals rather than asking users to score relationships on a raw numeric scale.
