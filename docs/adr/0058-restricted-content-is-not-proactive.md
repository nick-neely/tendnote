# Restricted Content Is Not Proactive

Phase 1 retrieval should exclude restricted source records and memories from proactive surfaces such as daily briefs and message drafts by default. Normal content can be used in retrieval, briefs, and drafts; sensitive content can be used with careful phrasing and source grounding; restricted content should stay in review or profile contexts unless directly requested in the current turn and allowed by access rules.

This prevents Tendnote from unexpectedly surfacing delicate context while still allowing the user to retrieve it intentionally.
