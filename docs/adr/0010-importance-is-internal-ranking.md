# Importance Is Internal Ranking

Phase 1 includes `importance` as an internal ranking signal for retrieval, brief candidates, and context snapshots, but does not make users rate every memory or source record during capture. Defaults can be derived from memory kind, recency, explicit user language, save behavior, and later correction signals.

If ranking needs user correction, Tendnote should expose lightweight controls such as pinning or marking something important rather than making importance a required capture field.
