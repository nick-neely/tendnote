# Google Contacts Disconnect Keeps Confirmed Tendnote Data

Disconnecting Google Contacts should revoke provider access and stop future preview fetches, but it should not delete people, emails, phone numbers, birthdays, or other profile data the user already confirmed into Tendnote. Confirmed imports become Tendnote-owned relationship data; provider-link metadata may be removed or marked disconnected when appropriate, but the confirmed profile data remains editable in Tendnote.
