# Phase 6 Assets Use Evidence Not Document Management

Phase 6 should support Asset Evidence such as receipts, photos, warranties, manuals, links, retained extracted text, and maintenance notes only as grounding for Assets, Asset Memories, and related General Actions. It should not introduce a standalone document library, file manager, folder system, generic OCR workflow center, or all-documents product surface, because the useful product anchor for this phase is the Asset profile.
