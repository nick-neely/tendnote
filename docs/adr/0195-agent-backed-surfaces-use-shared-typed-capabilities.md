# Agent-Backed Surfaces Use Shared Typed Capabilities

Phase Seven purpose-built Today, search, review, and resurfacing surfaces should not run hidden Eve chat turns or recreate product policy: structured intent calls shared owner-scoped product functions directly, while reasoning uses the same named, typed Agent Capabilities that Eve reaches through thin tool adapters. Deterministic server policy remains authoritative for scope, eligibility, caps, approval, and fallback; capability results carry authoritative record references, grounding, and trust metadata, and any actionable or reloadable output must be persisted before a control can act on it. This keeps factual and safety behavior consistent across channels while allowing Eve to narrate and purpose-built surfaces to render compact task-appropriate interfaces.
