# Source Records Can Pend Person Resolution

Phase 1A source records may exist before all mentioned people are resolved. Ambiguous capture, such as notes about a person name that matches multiple people, should create a source record with lifecycle status such as `pending_resolution`, `active`, `dismissed`, or `archived`, plus person links as they are resolved.

Pending source records can appear in review queues, but unresolved mentions should not feed normal person profiles, daily briefs, message drafts, or memory extraction until the relevant person link is resolved or the user explicitly decides how to handle it.
