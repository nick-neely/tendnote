# General Actions Start With A Bounded Personal OS Action Model

Phase 5 General Actions should start with a richer Personal OS action model rather than only copying Follow-Up status behavior. General Actions may include lifecycle, due dates or cadence, defer/start timing, priority, effort or size, area or domain, visibility scope, source grounding, review promotion, and resurfacing semantics, while deferring subtasks, dependencies, kanban boards, project hierarchy, multi-assignee workflows, rich recurrence exceptions, and time tracking.
