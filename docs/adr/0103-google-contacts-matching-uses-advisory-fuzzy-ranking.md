# Google Contacts Matching Uses Advisory Fuzzy Ranking

Phase 2E should use deterministic signals such as normalized email and phone for high-confidence contact import matches, and may also use LLM or semantic fuzzy matching to rank possible Tendnote people with short human-readable reasons. Fuzzy matches should remain advisory and require user confirmation before linking or updating a person, so smarter duplicate detection improves the preview experience without silently attaching provider data to the wrong relationship profile.
