# Asset Search Unifies UI And Keeps Typed Retrieval

Phase 6 should give users one Asset Search experience across the Assets surface and Eve entry points, covering exact text such as serial numbers, model names, receipt amounts, and filter sizes as well as fuzzy intent such as warranties expiring soon or items related to the kitchen fridge. Underneath, exact recall and semantic retrieval should remain separate typed, scope-filtered contracts so Eve and UI components can cite records correctly and avoid treating generated answers as search truth.
