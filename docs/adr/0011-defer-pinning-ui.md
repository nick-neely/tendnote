# Defer Pinning UI

Phase 1A should not require explicit pinning or importance controls during capture. Tendnote can leave room for pinned memory references in context snapshots, but the user-facing pinning affordance should wait until the core memory, source record, retrieval, and brief loop produces results that need correction.

This keeps capture lightweight while preserving pinning as a later user correction signal for profile summaries, retrieval ranking, and daily brief relevance.
