# Related Asset Link Inference Is Review Gated

Phase 6 should create Related Asset Links directly only from explicit user intent, such as "this filter fits the kitchen fridge." Links inferred from receipts, manuals, photos, maintenance notes, source records, or Eve reasoning should enter review first so Tendnote does not silently build incorrect asset relationships. A later explicit automation or trusted-agent mode may reduce this review friction for low-risk links, but the Phase 6 default remains review-gated.
