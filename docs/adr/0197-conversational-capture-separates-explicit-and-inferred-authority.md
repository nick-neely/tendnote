# Conversational Capture Separates Explicit And Inferred Authority

Phase 7 conversational capture should execute a supported owner-scoped outcome directly when the owner explicitly requests it and its consequential fields are resolved, while outcomes inferred beyond that instruction remain review-gated. Tendnote saves the original input as source evidence before clarification, permits multiple explicitly requested outcomes, and falls back privately to a Saved Item when no better supported destination is clear; this keeps capture fast enough to use without letting model interpretation masquerade as owner authority.

Clarification is reserved for ambiguity that could change a person, date, scope, durable fact, lifecycle, or external effect. Successful writes receive compact destination-aware confirmation and correction controls, while failed writes remain visibly unsaved and retryable; correction reroutes the same grounded capture rather than creating an unexplained duplicate.
