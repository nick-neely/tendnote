# Manual Follow-Ups Before Suggested Follow-Ups

Phase 1 should implement manual follow-ups before agent-suggested follow-ups. Manual follow-ups prove the core reminder contract: person links, due dates, statuses, snooze, complete, dismiss, audit logging, and daily brief inclusion.

Agent-suggested follow-ups can reuse the same lifecycle and review UI later, after Tendnote has enough behavior and examples to avoid noisy or annoying suggestions.
