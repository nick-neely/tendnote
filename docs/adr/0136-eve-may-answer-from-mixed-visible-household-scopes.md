# Eve May Answer From Mixed Visible Household Scopes

Phase 4 should let Eve answer from the caller's visible context across private, shared, and household scopes so household behavior is useful. Eve must not reveal another member's private records, and when an answer blends scopes it should preserve provenance and scope-sensitive phrasing, such as distinguishing the caller's private notes from household context when that distinction matters; assistant components should carry record scope so rendering and actions cannot cross scopes accidentally.
