# Google Contacts Import Preview Uses a Dedicated Workflow Surface

Phase 2E should expose Google Contacts connection state and the primary import action from the account or settings provider row, then move the user into a dedicated import preview surface once they start. The provider row is too constrained for ranked candidates, search, conflict resolution, confirmation feedback, and post-import review, while a dedicated workflow surface can stay intuitive without making Contacts import feel like a dense ledger.
