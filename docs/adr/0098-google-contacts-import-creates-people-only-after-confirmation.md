# Google Contacts Import Creates People Only After Confirmation

Phase 2E should allow Google Contacts import preview rows to create new Tendnote people, attach contact methods or birthdays to existing people, skip rows, or require manual resolution, but only after explicit user confirmation. Tendnote should not auto-create people, run background contact sync, or introduce a full merge console in this phase; the preview should feel like confirming sensible suggestions rather than processing a ledger, while preserving user intent before provider data becomes durable relationship data.
