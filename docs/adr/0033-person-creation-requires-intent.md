# Person Creation Requires Intent

Phase 1A should not automatically create a new person from ambiguous capture. Explicit commands such as "add a person named Maya Chen" may create a person directly, but casual notes such as "had coffee with Maya" should create a pending source record and ask whether to add Maya, link to an existing person, or leave the record unresolved.

This protects quick capture without creating accidental duplicate people or silently expanding the relationship database from uncertain references.
