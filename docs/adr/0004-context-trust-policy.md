# Context Trust Policy

Phase 1 retrieval uses trust levels in addition to memory lifecycle status. Approved memories and structured fields are confirmed facts; source records are source-grounded context that must be phrased as "you noted", "you logged", or "you mentioned"; suggested memories are tentative hints that may influence briefs or optional draft context but cannot be stated as fact.

Dismissed observations must not be used, and unapproved sensitive observations are review-only until approved. This keeps Tendnote useful before every small detail is manually promoted while preserving the rule that only approved memories are durable relationship facts.
