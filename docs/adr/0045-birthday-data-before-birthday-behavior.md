# Birthday Data Before Birthday Behavior

Phase 1A should keep birthday as basic person profile data, but birthday-specific assistant behavior should wait until daily briefs and drafting are ready. Same-day birthday prompts, upcoming birthday warnings, belated-message handling, gift-idea surfacing, and birthday draft tone should build on the brief and draft systems.

This keeps the person model complete without pulling a full birthday protocol into the first source-record and memory slice.
