# Asset Memories Use A Small Typed Shape

Phase 6 Asset Memories should support both structured values and freeform notes through a small typed shape, such as kind, label, value or text, relevant date/amount/link metadata, evidence references, sensitivity, scope, and review state. This gives Eve, exact recall, and Asset profiles reliable handles for facts like filter size, serial number, purchase date, warranty expiration, and maintenance notes without creating a custom schema for every Asset Kind.
