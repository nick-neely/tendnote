# General Actions Can Carry Asset Hints Before Asset Memory

Phase 5 General Actions may carry lightweight object or asset hints, such as a subject label for "refrigerator water filter" or "car registration", so future Asset/Object Memory can link or promote them without rework. Phase 5 should not introduce durable asset records, asset profiles, warranties, documents, serial numbers, maintenance history, or asset-specific search; those remain Phase 6 scope.
