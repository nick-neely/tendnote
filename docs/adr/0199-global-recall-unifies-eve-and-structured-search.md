# Global Recall Unifies Eve And Structured Search

Phase Seven should expose one owner-scoped Global Recall capability to both Eve and the lightweight structured search overlay rather than giving conversation a hidden broader retrieval universe. Exact lexical and semantic retrieval remain distinct, typed candidate paths, but the server applies the same permissions and lifecycle policy, merges them into one discriminated result contract, and returns canonical record references, grounding, match explanations, trust metadata, and deep links. Eve may synthesize and cite those results while search presents them directly with progressive disclosure; neither channel may treat generated prose as retrieval truth. This preserves a consistent privacy and grounding boundary across conversational and purpose-built recall while allowing each surface to use interaction patterns suited to its task.
