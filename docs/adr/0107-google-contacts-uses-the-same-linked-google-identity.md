# Google Contacts Uses the Same Linked Google Identity

Phase 2E should request Google Contacts as a separate provider capability and incremental scope, but it should use the same linked Google identity already used for the owner's Google Calendar or Gmail capabilities. If a Contacts connection would use a different Google account, Tendnote should block it with a clear explanation rather than blending provider data from multiple Google identities before the product has explicit multi-account provenance, revocation, and user-expectation rules.
