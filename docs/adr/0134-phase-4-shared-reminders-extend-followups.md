# Phase 4 Shared Reminders Extend Followups

Phase 4 shared reminders should extend the current person/relationship Follow-Up model with private, shared, and household visibility rather than introducing the broader non-person general reminders/actions model early. This keeps Phase 4 focused on the Household Workspace permission foundation while preserving room for Phase 5's general reminders/actions foundation and later household OS behavior to feed into the same workspace.
