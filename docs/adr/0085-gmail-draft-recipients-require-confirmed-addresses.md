# Gmail Draft Recipients Require Confirmed Addresses

Phase 2D should let Gmail draft recipients come from an existing Tendnote person contact method or from an address the user explicitly provides at draft-creation time. If the address is not already attached to the person, Tendnote should use it only as action-specific external draft recipient metadata unless the user separately confirms saving it as a durable contact method. This keeps Gmail draft creation useful before Google Contacts import while preventing a draft action from silently becoming contact import or profile enrichment.
