# Follow-Up Lifecycle Status

Phase 1 follow-ups use lifecycle statuses: `suggested`, `open`, `snoozed`, `completed`, `dismissed`, and `archived`. `suggested` means the agent proposed an action that is not yet an active reminder; `open` means an accepted or manually created active reminder; `snoozed` delays an active reminder until a new due date; `completed` records that the user did it; `dismissed` rejects the reminder or suggestion; and `archived` hides it from normal views while retaining history.

Daily briefs should prioritize due `open` and due `snoozed` follow-ups. Suggested follow-ups may appear only when there is room and the reason is strong enough to avoid turning the brief into an automatically generated task list.
