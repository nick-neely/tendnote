# Phase 6 Adds Lightweight Related Asset Links

Phase 6 should support explicit or review-gated Related Asset Links so useful relationships such as a filter fitting a refrigerator, tires belonging to a car, a service plan covering an appliance, or a charger being used with a laptop are not lost. These links should remain lightweight profile and retrieval context, and should not introduce full asset hierarchies, component trees, inherited permissions, inventory rollups, cascading lifecycle rules, or graph workflows in the first slice.
