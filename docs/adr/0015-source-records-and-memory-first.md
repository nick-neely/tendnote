# Source Records And Memory First

Phase 1A should implement source records and memory lifecycle before follow-ups, briefs, and drafting. The first vertical slice should add the `source_records` table and domain schema, memory lifecycle fields and statuses, shared owner-scoped mutations with audit logging, and UI/agent flows for explicit "remember" requests, logged notes, extracted suggested memories, and save, edit, or dismiss review.

Follow-ups, persisted briefs, context snapshots, full-text search, semantic retrieval, and message drafting should build on this evidence and memory foundation rather than each inventing its own context model.
