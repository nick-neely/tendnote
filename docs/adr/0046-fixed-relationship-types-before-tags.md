# Fixed Relationship Types Before Tags

Phase 1A should keep a small fixed `relationship_type` enum for simple profile filtering and defaults. Flexible tags or labels can be added later if real grouping needs emerge, such as church, college, pickleball, local friends, or consulting network.

Deferring tags avoids early taxonomy management and keeps Tendnote from drifting toward CRM-style segmentation before the personal relationship loop is useful.
