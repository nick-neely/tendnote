# Sandbox Cleanup Produces Previews

Phase 3 sandbox-backed cleanup should prepare reviewable cleanup previews from owner-supplied messy private input such as CSV/vCard files, pasted lists, old notes, exported text, or JSON, not act as a broad autonomous import system. The sandbox may parse, normalize, and dedupe candidates, but durable people, memories, contact methods, source records, and follow-ups still require confirmation through Tendnote review surfaces, and Google Contacts import remains a separate provider-specific workflow.
