# Fixed Typed Assistant Components

Phase 1A assistant responses may include structured UI components, but only from a small fixed typed set curated by the app, such as source record cards, suggested memory review, suggested follow-up review, person disambiguation, draft review, and brief items. The assistant can choose when these components are useful, but the app owns the component schemas, allowed actions, and visual composition.

Agent-authored arbitrary components may be explored later as a design-system-constrained experiment, but Phase 1A should not let the model invent UI schemas, actions, or unsafe flows.
