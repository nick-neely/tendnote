# Asset Extraction Is Review Gated

Phase 6 should create active Assets and Asset Memories directly only from explicit user intent. Asset-like information inferred from source records, receipts, photos, warranties, maintenance notes, Discord captures, or promoted action hints should enter review first as Suggested Assets or Suggested Asset Memories, preserving Tendnote's existing pattern that inferred durable context is proposed before it becomes truth.

A later explicit automation or trusted-agent mode may reduce review friction for low-risk asset updates, but that should be introduced as its own consented capability with clear boundaries rather than smuggled into the Phase 6 default.
