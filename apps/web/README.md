# @tendnote/web

Next.js App Router workspace for Tendnote.

- App shell and people views live under `src/app`.
- Better Auth routes live under `src/app/api/auth/[...all]`.
- shadcn/ui components live under `src/components/ui`.
- AI Elements components live under `src/components/ai-elements`.

Run from the repository root:

```bash
pnpm dev:web
```
